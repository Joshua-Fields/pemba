# Benchmark results

> **`write_batch_*`: Rust and Python are not comparable yet (OQ-040).** Criterion writes a fresh batch into the same database on every iteration, thousands of them, and the Rust latency pass then runs on that grown database; the Python bench writes 30 batches. On SQLite the two measure different table sizes, so compare each language's write figures only with themselves. SpiceDB's `write_batch_100` (about 44 ms, slower than its `write_batch_1000`) looks like a delayed-ACK stall in the bench's HTTP transport rather than SpiceDB: do not quote it.

Generated by `python benches/results.py`; do not edit by hand. Scenarios and datasets: `docs/07-testing.md` §7 and `benches/src/lib.rs`. All figures are µs per operation (wall clock, one call at a time, warm caches). `lookup_*` figures cover every page of the lookup. No performance targets are fixed yet (OQ-008).

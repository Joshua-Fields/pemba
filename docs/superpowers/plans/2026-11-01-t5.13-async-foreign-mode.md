# T5.13 async foreign mode implementation plan

**Goal:** Implement the already approved thread bridge in `10-postgres.md` §2.4,
after stable publication, without changing synchronous evaluation or transaction ownership.

**Scope authority:** T5.13, OQ-003/OQ-055/OQ-058, ADR-003/ADR-006/ADR-015 and the
maintainer's explicit instruction to implement this task. T7.17 is separate human work.
No sans-IO redesign, runtime dependency, package version or release artifact changes.

**Architecture:** The native `Engine.write_async` returns a Python coroutine. Python
validates/unpacks the async driver on its loop, then runs existing `Engine.write` in
`asyncio.to_thread`. An internal connection bridge lets the existing Rust `WriteTxn`
schedule driver operations with `run_coroutine_threadsafe(...).result()`. Driver objects
and cursors stay on their loop. Dollar placeholders reach asyncpg unchanged; psycopg
uses the existing format conversion and SQLSTATE mapping. No duplicated write algorithm.

**Review focus:** Never commit caller transactions; errors remain exceptions; never use
async connections off-loop; drain workers before cancellation permits rollback; preserve
the sync guard against raw async connections. No optional driver imports at runtime.

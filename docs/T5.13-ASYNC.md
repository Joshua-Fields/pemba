## Acceptance coverage

| Criterion | Implementation / evidence |
|---|---|
| `write_async`, specified thread bridge | Native method returns the Python coroutine; `asyncio.to_thread` runs existing synchronous `Engine.write` / shared Rust write algorithm. Each driver operation is scheduled on the caller's loop by `run_coroutine_threadsafe(...).result()`. No async Rust store/runtime or sans-IO redesign. |
| Required drivers | psycopg `AsyncConnection`, asyncpg `Connection`, SQLAlchemy `AsyncSession` and the explicitly specified `AsyncConnection`, over both drivers. Driver inspection, operations, fetching and cursor cleanup stay on-loop; pemba imports no optional driver. SQLAlchemy materializes its deferred asyncpg transaction through its own execution API. |
| Caller transactions / errors | Existing database identity, placeholder conversion, write validation, preconditions and SQLSTATE mapping retained. Caller commits/rolls back; only OQ-055's raw-psycopg autocommit opt-in lets pemba own a transaction. Sync `write` still rejects raw async connections. Exceptions never become denial. |
| Async reads | Typed `pemba.aio.check`, `lookup_resources`, `lookup_subjects` and `resolve(pending)` forward synchronous results/consistency/errors through `to_thread`. Reads use engine connections. |
| Cancellation | Stop further statements, drain in-flight SQL and worker before `CancelledError`, including repeated cancellation; caller must then roll back. Cancellation may wait for a database statement. Reads retain documented coarse worker cancellation. |
| Bridge benchmark | [Method and results](../benches/RESULTS.md#t513-async-foreign-statement-bridge-windows-docker-postgres), [script](../crates/pemba-py/bench/async_bridge.py), [raw samples/environment](../benches/t5.13-async-bridge.json). Median paired block-p50 deltas: psycopg 184.8 µs, asyncpg 177.3 µs; no-op bridge p50/p99 130.5/294.0 µs. No workload budget or performance threshold established; retain bridge, consider a separate sans-IO follow-up only if representative full-write profiling warrants it. |
